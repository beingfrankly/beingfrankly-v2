# Hello World

Welcome to my new blog built with Astro and Content Collections!

This is a sample post to demonstrate the new content structure. The content is now managed through Astro's Content Collections, which provides:

- Type safety with Zod schemas
- Predictable content structure
- Better developer experience
- Static site generation

## Features

- **Type Safety**: All content is validated against the schema
- **SSG**: Static site generation for better performance
- **Content Collections**: Organized content management
- **Markdown Support**: Rich content with frontmatter
